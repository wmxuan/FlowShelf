# FlowShelf 浏览器扩展

Chrome MV3 扩展，Phase 2 开发。

## 功能规划

- 一键收藏（点击图标）
- AI 智能分流（工具/文章/视频）
- Tab 数量统计
- Tab AI 归组

## 开发命令

```bash
# 安装依赖
npm install

# 开发模式
plasmo dev

# 构建
plasmo build
```

## 加载扩展

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启开发者模式
3. 点击"加载已解压的扩展程序"
4. 选择本目录的 `build/chrome-mv3-dev` 目录
